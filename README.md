# dotbot — Telegram-бот с командами через точку

Бот на `python-telegram-bot`, понимает команды вида `.help`, `.anim текст` и т.д.
Работает как обычный бот в группах/лички, а также может быть подключён
через **Telegram для бизнеса** (Premium-функция) прямо к вашему личному аккаунту.

## Команды

| Команда | Что делает |
|---|---|
| `.anim [текст]` | Плавная анимация появления текста по буквам |
| `.help` | Список команд |
| `.info` | ID и примерная дата регистрации собеседника (ответом на сообщение — покажет того, кому ответили) |
| `.mute` | Замьютить пользователя (ответ на его сообщение, только в группах, только у админов) — бот удаляет все его новые сообщения |
| `.unmute` | Снять мут |

## Структура проекта

```
dotbot/
├── bot.py           # точка входа
├── config.py        # загрузка настроек из .env

├── handlers.py       # логика команд
├── utils.py           # анимация текста, оценка даты регистрации по ID
├── requirements.txt

└── .gitignore
```

## Установка (локально / на сервере)

1. Клонируешь репозиторий:
   ```bash
   git clone https://github.com/твой_логин/dotbot.git
   cd dotbot
   ```
2. Создаёшь виртуальное окружение и ставишь зависимости:
   ```bash
   python -m venv venv
   source venv/bin/activate   # Windows: venv\Scripts\activate
   pip install -r requirements.txt
   ```
3. Копируешь `.env.example` в `.env` и вписываешь токен от [@BotFather](https://t.me/BotFather):
   ```bash
   cp .env.example .env
   ```
4. Запускаешь:
   ```bash
   python bot.py
   ```

База данных `bot.db` (SQLite) создаётся автоматически рядом со скриптом при первом запуске.

## Деплой из GitHub (чтобы бот работал 24/7, а не только пока запущен на компе)

GitHub сам код не исполняет — нужен отдельный хостинг, который подтянет репозиторий и запустит `bot.py`. Проще всего:

- **Railway** или **Render** — подключаешь GitHub-репозиторий, задаёшь переменную окружения `BOT_TOKEN` в настройках проекта, команда запуска `python bot.py`. Деплой обновляется автоматически при пуше в репозиторий.
- **VPS** (любой сервер) — `git clone`, ставишь зависимости, запускаешь через `systemd` или `screen`/`tmux`, чтобы бот жил после отключения SSH.

Токен в `.env` в репозиторий **не коммитится** (он в `.gitignore`) — на хостинге его нужно будет задать отдельно как переменную окружения.

## Подключение через Telegram Premium (Telegram для бизнеса)

Это позволяет боту отвечать в твоих личных чатах от твоего имени:

1. В Telegram: **Настройки → Telegram для бизнеса → Чат-боты**.
2. Подключаешь своего бота по username.
3. Разрешаешь доступ к нужным чатам (все / кроме исключений).
4. После этого бот получает сообщения из твоих личных чатов как business-апдейты — код это уже поддерживает (`filters.UpdateType.BUSINESS_MESSAGES` в `bot.py`).

⚠️ Команды `.mute` / `.unmute` рассчитаны на группы (нужен статус админа), в личных business-чатах не применяются.

## Важные ограничения

- `.info` показывает **приблизительную** дату регистрации — официальный Bot API точную дату не отдаёт, оценка идёт по диапазону ID.
- Для реального удаления сообщений в группах (`.mute`) бот должен быть админом с правом «Удаление сообщений».
